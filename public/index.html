How it works

Same paper in, same report out

The checks work like a spell checker, not like a chatbot. That is what makes the results trustworthy.

  1. Add your paper

    Drop a .tex, .docx or .pdf file. It is opened inside your browser.

  2. Fixed rules check it

    Each rule is a precise test, for example "every number in the abstract must also appear in the paper".

  3. Fix and run again

    Run the same paper twice and you get the same list. When an item disappears, your fix worked.

Not sure what an issue means?

Every issue in the report has a "Why it matters" note. Open it to see, in plain words, why reviewers care about that issue and how to fix it.

  • The notes are written in advance for each rule, so they are always the same and work offline.
  • They explain issues. Only the rules decide your score and what gets flagged.

Why it matters

Reviewers compare the abstract with the results first. A number that appears only in the abstract looks like a typo or a result from an older draft.

How to fix it. Copy the final value from your results table, or remove the number from the abstract.

Privacy

Share only the results

Share creates a link a co-author can open. It contains the score and the list of issues, never the paper itself.

Shared links expire

A shared report is deleted 30 days after you create the link. After that, the link shows "not found".
